# GitHub Credential Rotation

A test project for experimenting with GitHub Actions and automated GitHub PAT credential rotation.

## Purpose

This repository is used to test:

- GitHub Actions
- GitHub authentication
- Automated credential rotation
- Integration with an external Secrets Vault backend
